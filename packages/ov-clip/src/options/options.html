Save to OpenViking

This extension stores no credential. It asks ovx for a token every time it saves, and ovx renews that token from your Vault session — so there is no password here, nothing to paste, and nothing left on disk when Firefox closes.

Where files go

viking://~ is OpenViking's home alias — it resolves to whoever your token says you are, so nothing here has to know your user id. Leave empty to hide this option.

Setting it up

  1. Install ovx, and make a profile: ovx -n
  2. Sign in once: ovx --login <profile>
  3. Let this extension ask ovx for tokens: ovx --install-firefox-host
  4. Restart Firefox, then press Check again above.
